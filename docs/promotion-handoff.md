## 按原任务约定录制

形式为约 90 秒产品介绍：功能标题 → 实际操作 → 效果。用户录制真实操作和对白，原宣传任务负责剪辑、字幕、封面、配乐、三张贴吧图和文案。新增采购预算为零；测试不批量调用付费模型。

| 成片位置 | 核心画面 | 原片操作与建议时长 |
|---|---|---|
| 0–7 秒 | 小吉终端名称与主界面 | 主界面静止后自然操作，15–20 秒 |
| 7–19 秒 | 角色选择 | 浏览列表、搜索、选择；30–40 秒，角色总数以最终公开目录为准 |
| 19–35 秒 | 文字通讯 | 里芙的真实输入、发送及回复，30–60 秒 |
| 35–53 秒 | 面对面 | 芬妮和卜卜各录进入界面、实际互动、表情；各 30–60 秒 |
| 53–67 秒 | 上下文延续 | 胧嫣同话题两三轮真实问答，45–90 秒 |
| 67–79 秒 | 角色资料交流 | 辰星一段自己能够核对的设定话题，30–60 秒；不大段复述剧情 |
| 79–90 秒 | 体验入口和使用条件 | 主界面收尾，片尾由制作任务完成 |

优先 1920×1080、30fps，窗口尺寸/缩放保持一致。模型配置提前完成，密钥输入和账户配置不录入画面。每段前后留约三秒，保留实际等待与原始回复；后期缩短等待时标注“等待已缩短”。对白由用户构思，不强制按预设台词生成。

## 新增统计告知如何呈现

首次提示和持续“统计与隐私设置”入口已经验收。两站分别选择，不以允许统计作为聊天的前置条件；测试浏览器最后已在两站撤销。可补录一段约 8–12 秒的设置演示，是否放进正片由节奏决定，使用说明和贴吧文案保留简短告知。

建议说明：

> 访问统计由你选择是否允许，可随时在统计与隐私设置中撤销。另有脱敏生成完成日志用于服务质量统计，不采集聊天正文或密钥。

公开页如无足够样本，应直接显示实际“等待公开”“样本不足”或无数据状态，不用假数字填画面。接口不可用应说明暂不可用，不能解释成零人使用。访问组按匿名标识判断，不等同自然人数；服务质量分母是**已记录的生成请求**，不等于所有 HTTP 请求或聊天尝试。样本门槛和延迟公开用于降低暴露风险，不保证完全匿名。

## 可以表达及需要避免的内容

- 角色目录、主界面、角色选择、统计选择与撤销已在正式页面验证。文字回复、面对面效果、上下文联系及角色资料准确程度，应由本次真实录制逐段核对；不能以技术测试或功能入口存在代替实际效果。字幕与对应真实画面一致。
- 片尾注明：非官方 AI 互动项目，需要连接自己的模型服务，费用或额度由对应账户承担。
- 不将有限上下文描述成永久记忆，不将角色资料辅助描述成回答绝对准确；不加入未开放的公网语音能力。
- 不把本地合成实验的百万条、恢复成绩或 P95 写成正式用户规模、生产 SLA 或物理机容灾能力。
- 统计页面不是核心聊天功能的依赖；电脑关闭或本地数仓停止不应被描述为产品停机。
