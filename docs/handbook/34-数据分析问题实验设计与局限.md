# 34 数据分析问题、实验设计与局限

## 从数字转向可回答的问题

数据开发负责让数据可信、可重复地到达分析层；数据分析负责用正确口径解释业务。这个项目适合同时练习，但小流量、可拒绝采集、匿名ID可重置意味着数据不是完整总体。应先问“这些数据能回答什么”，再计算。

可回答的问题包括：同意访问统计的人在已观察窗口内主要看哪些允许页面；哪些入口点击在30分钟内关联到记录的成功完成；不同内容分类变更前后按历史归属的表现；工单状态机中重开对处理时长的影响。不能仅凭匿名访问事件推断所有自然人的需求，也不能从几条成功日志得出服务绝对可靠。

```mermaid
  Q[业务问题] --> D[确定对象 分母 时间窗]
  D --> C[检查覆盖和偏差]
  C --> M[计算与对账]
  M --> I[解释边界和下一步行动]
```

## 推荐的分析记录模板

每次记录问题、决策用途、数据来源、观察范围、指标定义、纳入/排除规则、数据完整性、计算代码、结果和限制。结果为0、空、未成熟和被抑制时分别解释。结论应回到具体决策，例如“需要补充项目页对小吉的说明”，而不是只写“PV上升”。

这里的推荐来自本项目工作方式，不是对线上商业收益的保证。真实数据不足时可以演示分析方法，但必须用synthetic标签，不拿模拟器产生的增长曲线证明产品受欢迎。

## 实验一：渠道入口是否带来有效试玩

定义入口点击为一个有效jump_id，主转化为30分钟内最近有效入口关联的成功完成，每个点击最多计一次。分母是符合条件且观察窗口完整的点击，而非所有页面PV。两站需各自同意，拒绝访问统计会使链路不可观察；分析报告说明“可观测且已同意样本”。

练习设置A渠道10个点击，6个在窗口内成功，2个超过30分钟，1个请求失败，1个未观察完。若最后一个未完成观察，成熟分母9，转化6/9；若报告还展示全部点击10，应明确未成熟1，不能把它直接当失败。合成运营数据可设计多个渠道，但这不是随机对照试验。

## 实验二：分类调整后内容表现

用发生时SCD2归属回答“当时这个分类有多少访问”，用当前分类重组回答“现在这些内容的历史总表现”。两张报表可能都正确，但问题不同。分类迁移导致某分类下降，不能立即解释为内容吸引力下降；应拆分分类规则变化和真实访问变化。

练习：文章A旧类为数据，变更后为工程；变更前100PV、之后20PV。历史口径数据100/工程20，当前口径工程120。将当前口径工程120与历史口径工程20相比会制造虚假增长。

## 实验三：工单效率与重开

分别看首次解决时长、最近解决时长、每轮处理时长与重开率。平均值会被极长工单拉高，可同时展示中位数/分位数，但需要说明样本量。尚未解决工单没有最终解决时长，不应填0后参与平均；可独立显示在办时长。

练习：两张已解决工单耗时10和90分钟，一张未解决已等待120分钟。已解决平均50分钟，在办等待120单独列。把未解决填0得到33.3分钟，会让队列堆积时指标反而变好。

## 小样本和偏差如何表达

用户自愿同意造成选择偏差；匿名ID清除造成同一人多个标识；跨设备不合并造成计数范围限制；广告拦截和网络丢事件造成缺失；本机离线超过保留期造成历史覆盖缺口。以上应写在分析限制，不能用“匿名UV”三个字掩盖。

公开小计数抑制是披露控制，不是统计显著性，也不是匿名保证。内部精确数据可用于受控排查，公开页有延迟和整组抑制；不能通过额外接口、截图或每日差值泄露被隐藏计数。

## 练习与答案

题：A渠道转化率80%、B渠道50%，能否把预算全部投A？答案：先看分母、观察成熟度、同意选择、渠道用户差异和是否随机分配。若A只有5个点击，单纯率差不足以支持强决策。这个项目更适合提出下一轮采样或页面改进假设，而非过度推断因果。
